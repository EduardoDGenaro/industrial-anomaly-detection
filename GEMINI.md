# Diretrizes do Projeto - Inspeção Visual Automatizada

## Política Estrita de Não Utilização de Emojis
- É terminantemente proibido o uso de emojis em qualquer texto, resposta, documentação, comentário de código ou elemento de interface do usuário (UI).
- Elementos gráficos na interface (Streamlit / HTML) devem utilizar exclusivamente classes CSS semânticas (padrão ISA-101), badges de texto limpos (ex: `[APROVADA]`, `[REJEITADA]`) ou indicadores geométricos discretos (`• ONLINE`).
- Botões e ações devem conter apenas texto claro e descritivo (ex: "Contestar Falso Alarme", "Exportar Laudo Técnico", "Confirmar Homologação").
- Todas as explicações e relatórios técnicos devem manter tom formal de engenharia e controle de qualidade industrial.
